# E-Riš-Assistant
**E-riš** je spletna aplikacija in pametni šolski pomočnik za dijake ter zaposlene. Glavna funkcija je varen AI asistent z vgrajeno cenzuro, ki odgovarja na vprašanja o šoli in zanimivostih. Pomožne strani vključujejo urnik, interaktivno mapo šole, kontakte profesorjev ter predstavitev razvoja projekta na enem mestu za lažji šolski vsakdan
